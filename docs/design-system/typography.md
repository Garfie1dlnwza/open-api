# Typography

IBM Plex Sans Thai for Thai and Latin text, IBM Plex Mono for code. Both self-hosted through
`@fontsource` (no third-party request, no layout shift from a late font swap). Fallback:
Noto Sans Thai, system sans.

| Token | Size / weight |
|---|---|
| display | 36 / 700 |
| h1 | 32 / 700 |
| h2 | 24 / 600 |
| h3 | 20 / 600 |
| h4 | 16 / 600 |
| body | 16 / 400 |
| small | 14 / 400 |
| caption | 12 / 400 |
| code | 13 / 400 |

Body line-height is 1.6 and headings 1.3: Thai tone marks need a taller line box than Latin.
